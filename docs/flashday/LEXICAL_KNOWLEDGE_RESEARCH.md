# FlashDay Lexical Knowledge Research

Status: research source-of-truth  
Scope: durable findings from WORD BANKS, My Topics/OALD-inspired thematic organization, UNLOCK YOUR VOCABULARY, VOA integration, and existing FlashDay research.

## 1. Purpose

Record product and learning-system insights from reviewed references without treating copyrighted source prose as production content.

The three reference patterns solve different problems:

- **WORD BANKS**: depth — how to teach an important lexical item richly.
- **My Topics**: breadth — how to organize a lexical universe by semantic domain.
- **UNLOCK YOUR VOCABULARY**: morphology — how word parts can support inference, word-family awareness, and word formation.

VOA remains the authentic encounter/audio layer. FlashDay's evidence kernel remains the source of learner truth.

### 2.3 UNLOCK YOUR VOCABULARY — CARDIO / NEURO / DERMA

Reviewed directly from Drive file:

Observed instructional pattern:

```
morpheme/root
-> core semantic contribution

```

Examples in the sample show families around:

- `cardio-` / heart;
- `neuro-` / nervous system;
- `derm-/derma-` / skin.

The exercise page adds:

- meaning matching;
- constrained gap fill;
- multiple-choice concept checks.

Durable finding:

> Morphology should be represented as a reusable inference layer over lexical concepts, not as a separate vocabulary list.

It is especially useful for:

- academic word decoding;
- word-family discovery;
- word formation;
- unfamiliar-word inference;
- spelling/meaning relationships;
- domain-specific terminology.

But:

```
correct morpheme inference != known word
```

and:

```
same visible root != same modern meaning
```

Morphological decomposition must therefore carry confidence and exception/warning support.

## 4. Product lessons

### 4.1 Collocations are first-class

Learners often know a base meaning but cannot produce natural combinations.

Represent collocations separately from definitions.

### 4.2 Constructions are first-class

Represent grammar frames tied to a lexical concept, e.g. verb-object, adjective-preposition, or transformation patterns.

### 4.3 Confusable words need structured contrasts

Near-synonyms should not be treated as interchangeable.

Contrast dimensions may include:

- meaning;
- register;
- region;
- grammar;
- countability;
- collocation;
- context;
- pragmatics.

### 4.4 Vietnamese-specific errors should be structured knowledge

Useful error classes:

- preposition;
- countability;
- article;
- number;
- word form;
- direct translation;
- collocation;
- false friend;
- register;
- regional-form confusion.

The same error ontology should later support vocabulary, writing and speech feedback.

### 4.5 Regional variation should be structured

Forms such as BrE/AmE spelling and pronunciation should be explicit so future speech evaluation can accept legitimate variants.

### 4.6 Semantic domains are not prerequisites

Topic/domain organization improves discovery and transfer, but must never silently become course order.

```
domain membership != prerequisite
```

### 4.7 Topic membership is not teaching priority

A domain can contain A1 words beside specialist terms.

Candidate teaching priority should use:

```
domain relevance
× learner level
× frequency
× communicative utility
× capability need
× prior exposure
× recycling opportunity
```

### 4.8 Morphology is an inference aid, not mastery

Morpheme knowledge can help a learner infer an unfamiliar word, but FlashDay must separately track whether the lexical concept was:

- encountered;
- recognized;
- recalled;
- used correctly;
- retained;
- transferred.

### 4.9 Controlled + authentic context

Use independently authored controlled examples for clarity, then rights-cleared VOA encounters for natural re-encounter.

## 5. Exercise primitives worth retaining

Extract reusable interaction primitives, not fixed copyrighted worksheets:

- definition recognition;
- contextual multiple choice;
- constrained gap fill;
- collocation assembly;
- word formation;
- morpheme decomposition;
- prefix/root/suffix inference;
- preposition/construction completion;
- synonym/antonym discrimination;
- L1→L2 constrained recall;
- cloze;
- sentence production;
- sentence transformation;
- contextual transfer.

## 6. Copyright / provenance boundary

The reviewed books are useful references for pedagogy and information architecture.

Do not build:

```
commercial PDF
-> bulk parser
-> production dictionary database
```

Do not assume rights to republish at scale:

- commercial definitions;
- example sentences;
- readings;
- synonym notes;
- usage notes;
- exercise text;
- entire commercial taxonomies;
- full word-family pages.

Production data must be independently authored or come from sources whose reuse rights are explicit.

Unknown rights fail closed.

## 8. Durable conclusions

1. Vocabulary must become a rich knowledge graph, not a translation table.
2. Semantic-domain coverage and curriculum order are separate.
3. Collocations/constructions are first-class.
4. Vietnamese learner errors are reusable cross-skill knowledge.
5. Regional variants matter for future speech.
6. Morphology should be modeled explicitly with confidence and exceptions.
7. Authentic encounters do not mint mastery.
8. Learner lexical state must be separate from lexical knowledge.
9. The same lexical layer should serve vocabulary, reading, listening, writing and speech.
10. Commercial references inform architecture; they are not automatic ingestion sources.


## 9. Thematic Vocabulary in Use — context-first vocabulary learning

Reviewed directly from the uploaded sample PDF `TVIU_GreenPacking Sample.pdf`.

The uploaded sample is **Chapter 01 — Green Packaging**, not the separately mentioned Bullying chapter.

The sample states a 30-unit, 10-theme course structure in which each chapter contains:

- a reading passage;
- an enriched bilingual vocabulary table;
- exercises;
- recurring collocation banks, extra practice and review tests by theme.

The reviewed Green Packaging lesson uses the following sequence:

```
thematic reading
→ visually highlighted target vocabulary in context
→ vocabulary table
→ IPA / POS / definition / contextual example / Vietnamese meaning+usage nuance
→ exercises
→ collocation practice
```

The vocabulary table is richer than a glossary. It includes:

- word/phrase;
- IPA;
- part of speech;
- English definition;
- independently contextualized example;
- Vietnamese gloss;
- Vietnamese note about register, nuance, collocation or usage.

The exercise sequence observed in the sample includes:

- definition matching;
- contextual gap fill;
- word formation;
- multiple-choice discrimination;
- collocation completion.

### 9.1 Durable finding: context should precede lexical decomposition

This source suggests a useful pedagogical ordering for many B1–C1 lexical units:

```
READ / LISTEN FOR MEANING
        ↓
notice target language in context
        ↓
inspect lexical knowledge
        ↓
retrieve / discriminate / transform
        ↓
produce
        ↓
re-encounter later
```

This differs from the common dictionary-first sequence:

```
word list
→ memorize
→ example
```

FlashDay should support both directions, but for thematic academic vocabulary the **context-first path** should be first-class.

### 9.2 Reading is a carrier, not proof of learning

Reading a passage that contains a word can create an encounter.

It does not prove:

- meaning recall;
- collocation control;
- production;
- retention;
- transfer.

Therefore:

```
highlighted_in_reading != learned
completed_reading != lexical_mastery
```

### 9.3 Highlighted lexical targets should be traceable into later tasks

A useful authored unit should be able to map:

```
passage occurrence
→ lexical concept/sense
→ collocation/construction
→ exercise primitive
→ later authentic re-encounter
```

This creates continuity instead of presenting a reading and an unrelated word list.

### 9.4 Word families should be integrated inside context-first units

The sample explicitly exercises word formation after introducing related forms in the vocabulary layer.

FlashDay should therefore be able to connect:

```
base concept
→ derivational family
→ in-context occurrence
→ word-formation task
```

This should reuse the Morpheme/WordFamily graph rather than create a separate exam-prep word-formation system.

### 9.5 Thematic review should recycle, not merely retest

The course structure includes collocation banks, extra practice and review tests after groups of chapters.

FlashDay should interpret this pattern as:

```
initial contextual encounter
→ focused retrieval
→ spaced thematic recycling
→ cross-topic reuse
```

rather than as a fixed printable test schedule.

### 9.6 Combine with VOA

The strongest FlashDay version is:

```
authored thematic reading
→ rich lexical unpacking
→ practice
→ VOA authentic re-encounter
→ retrieval
→ production
→ delayed transfer
```

This preserves readability for lower-confidence learners while still moving toward authentic input.
